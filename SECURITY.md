# Security policy

Bletide is experimental and has no supported stable release yet. Security fixes
will be developed against the current main development branch.

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Deuspheara/bletide/security/advisories/new)
when available. If private reporting is unavailable,
contact a maintainer through their public GitHub profile before sharing exploit
details. Do not put credentials, private hardware identities or exploitable
proofs of concept in public issues.

Include the affected revision/platform, impact, reproduction steps and a minimal
redacted example. The native ABI, foreign callbacks, payload decoding and resource
lifetimes are particularly relevant. No response-time guarantee is established.
